## What was built

### Scraper (`src/goodreads_scraper.py`)
Full CLI with 6 commands:

| Command | What it does |
|---|---|
| `login` | Opens real browser for manual Goodreads login, saves session to `auth_state.json` |
| `scrape --user-id` | Scrapes read/currently-reading/to-read shelves for one user into `person`, `book`, `person_book` tables |
| `friends --user-id` | Scrapes friend list, outputs IDs one per line (stderr for debug) |
| `details` | Enriches all books in `book` table with cover, description, genres, page count, top 5 quotes |
| `cache-load` | Imports `data/book_details_cache.json` into local `book_detail` table before scraping |
| `cache-save` | Exports `book_detail` to `data/book_details_cache.json` after scraping |

Key behaviours:
- `.env` is loaded automatically — env vars work whether you run via `run.sh` or directly
- `MAX_BOOKS` env var caps books per user for test runs (set to 10 in `.env` currently)
- `per_page=100` on shelf URLs — 5x fewer page requests vs default
- Profile page scraped at start of each user to populate `person.name` and `person.avatar_url`
- Book detail pages: graceful skip on timeout (retried next run), quotes page timeout returns empty quotes rather than skipping the whole book
- `goodreads_book_id` extracted from title link href — used as dedup key across users

### Pipeline (`run.sh`)
Three steps, fully automated:
1. Scrape own shelves
2. Scrape all public friends' shelves (8s pause between each, configurable via `FRIEND_SCRAPE_DELAY`)
3. Load cache → enrich books → save cache → git commit + push cache

### Database (`data/goodreads.db`)
Four tables matching `docs/schema.md`:
- `person` — users with name, goodreads_id, goodreads_url, avatar_url
- `book` — deduplicated books with goodreads_book_id, title, author
- `person_book` — shelf/rating/dates junction table
- `book_detail` — cover, description, genres (JSON), page_count, top_quotes (JSON)

### Shared cache (`data/book_details_cache.json`)
Committed to repo, no PII. Merges book detail data across runs so books only get scraped once across all contributors.

### Dependency management
Migrated from manual pip/venv to `uv` with `pyproject.toml` + `uv.lock`. `run.sh` auto-installs `uv` if missing.

### Debug tooling (`debug/`)
- `debug_shelf.py` — visits shelf page, saves screenshot + HTML to `debug/`
- `debug_friends.py` — visits friends page, saves screenshot + HTML to `debug/`
